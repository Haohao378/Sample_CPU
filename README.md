# MIPS-5Stage-Pipeline-CPU

## 🚀 项目简介

本项目实现了一个基于 **Verilog** 开发的 **MIPS32 五级流水线处理器**。该处理器严格遵循 MIPS 架构规范，实现了包括算术运算、逻辑运算、移位、分支跳转及访存等核心指令集。

本项目不仅展示了基础的五级流水设计，还深入攻克了**数据冒险（RAW）**、**控制冒险**以及**多周期运算指令（乘除法）引起的流水线停顿（Stall）**等高级体系结构难题。

## 🛠️ 核心技术亮点

* **五级流水线架构**：严格划分 IF, ID, EX, MEM, WB 级，实现了指令级并行。
* **全方位冒险处理**：
* **Data Forwarding**：通过多级旁路网络解决大多数原始数据依赖（RAW）。
* **Stall & Bubble 机制**：针对 Load-Use 冒险及多周期指令，实现了精确的流水线冻结与气泡插入逻辑。
* **迭代式乘法器 (`mul_plus`)**：自主设计的移位累加算法，支持**动态提前终止（Early Termination）**





## 📂 文件目录与模块解析

项目核心源码位于主目录下，各模块分工明确：

| 模块名称 | 文件名 | 功能描述 |
| --- | --- | --- |
| **顶层容器** | `mycpu_top.v` | 处理器最外层封装，对接指令/数据 SRAM 及调试接口。 |
| **流水线核心** | `mycpu_core.v` | 处理器顶层实例化，负责各流水级总线（Bus）的互联与信号传递。 |
| **取指级** | `IF.v` | 负责 PC 更新、分支跳转执行及指令 SRAM 接口访问。 |
| **译码级** | `ID.v` | **核心模块**。负责指令并行译码、寄存器读取、Load-Use 冒险检测及指令锁存。 |
| **执行级** | `EX.v` | 负责 ALU 运算、乘除法模块控制、访存地址计算及写数据对齐。 |
| **访存级** | `MEM.v` | 负责数据 SRAM 的读回处理、非对齐字节/半字扩展逻辑。 |
| **写回级** | `WB.v` | 负责结果写回寄存器堆及 Trace 调试信号的最终输出。 |
| **全局控制** | `CTRL.v` | **决策中枢**。接收各级停顿请求，生成全局 6 位 `stall` 控制总线。 |
| **专用寄存器** | `regfile.v` | 包含 31 个通用寄存器及专用的 **HI/LO** 寄存器堆。 |
| **运算增强** | `mul_plus.v` | 自研的 32 位乘法器，支持提前终止逻辑。 |

## 📊 指令集实现情况

本项目共实现了 MIPS32 规范中的核心指令：

* **算术运算**：`ADD`, `ADDU`, `SUB`, `SUBU`, `ADDI`, `ADDIU`, `SLT`, `SLTU`, `SLTI`, `SLTIU`
* **逻辑运算**：`AND`, `OR`, `XOR`, `NOR`, `ANDI`, `ORI`, `XORI`, `LUI`
* **移位运算**：`SLL`, `SRL`, `SRA`, `SLLV`, `SRLV`, `SRAV`
* **分支跳转**：`BEQ`, `BNE`, `BGEZ`, `BGTZ`, `BLEZ`, `BLTZ`, `J`, `JAL`, `JR`, `JALR`
* **访存指令**：`LW`, `LB`, `LBU`, `LH`, `LHU`, `SW`, `SB`, `SH`
* **专用寄存器访问**：`MFHI`, `MFLO`, `MTHI`, `MTLO`
